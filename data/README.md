# Demo data

[中文说明](README_zh.md)

This directory provides sample datasets for text SFT, tool-calling SFT, and image-text SFT.

- `alpaca_en_demo.json` and `alpaca_zh_demo.json`: text instruction data
- `identity.json`: identity question-and-answer data
- `glaive_toolcall_en_demo.json` and `glaive_toolcall_zh_demo.json`: tool-calling conversations
- `mllm_demo.json` and `mllm_demo_data/*.jpg`: image-text conversations and images
- `dataset_info.json`: dataset names, files, formats, and column mappings

The sample files can be used for format reference and local configuration validation.
