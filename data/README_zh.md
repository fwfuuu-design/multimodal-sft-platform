# 示例数据

[English](README.md)

本目录提供文本 SFT、工具调用 SFT 和图文 SFT 的示例数据。

- `alpaca_en_demo.json`、`alpaca_zh_demo.json`：文本指令数据
- `identity.json`：身份问答数据
- `glaive_toolcall_en_demo.json`、`glaive_toolcall_zh_demo.json`：工具调用对话数据
- `mllm_demo.json` 与 `mllm_demo_data/*.jpg`：图文对话及图片
- `dataset_info.json`：数据集名称、文件、格式和字段映射

这些示例可用于了解数据格式和验证本地配置。
